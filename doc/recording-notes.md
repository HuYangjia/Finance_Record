# AI 代录与备注范式

## 目的与适用范围

本规范由 `AGENTS.md` 引用，约束 AI 代录、系统自动备注及已授权的历史整理，不限制用户手填。备注仅补充结构化字段缺少的事实；投资数量、报价、现金尚无独立字段，仍须保留。

## 固定写法

采用“固定主体＋可选补充”：普通记录默认一句、尽量 40 字内，投资记录 1—3 个短分句、尽量 120 字内；同日多笔买卖可增加分句。未知字段省略，不猜填或留空模板；信息完整优先，不机械截断。

| 记录 | 固定主体 | 示例 |
| --- | --- | --- |
| 普通支出 / 收入 | 具体用途或事项；没有额外信息可留空 | `洗衣`、`实习工资尾款` |
| 投资转账 | 标的或用途＋补款 / 入金 / 转出 | `中国财险买入补款` |
| 投资费用 | 标的＋买入 / 卖出费用；组成（有拆项时） | `中国财险买入费用；组成36.88＋1.43 HKD` |
| 投资买卖与估值 | 买入 / 卖出＋标的＋数量×单价；现金；必要的持仓及估值依据 | `买入中国财险2000股×17.00 HKD/股；现金0 HKD；持仓暂按成本估值` |
| 仅录账户估值 | 报价来源或特殊估值依据；没有额外信息可留空 | `券商App总资产` |
| 自动估值损益 | 估值至＋目标总资产＋币种 | `估值至 34000.00 HKD` |
| 账户备注 | 一句用途或余额口径；仅重复名称则留空 | `基金定投`、`总资产含现金与持仓` |

### 允许的一点扩展

主体不足时仅追加一句 `补充：……`，例如“均价由入金减费用反推”“未提供后续市价”。保留以下必要事实：

- 原数量单位（“手”不能改成“股”）；无单价时写已知成交额，反推数字注明依据。
- 交易后现金、剩余标的及估值基础；待收 / 待付与可用现金分开写，必要时保留不同于成交日的交收日期。
- 仅在有依据时写“现金0”“清仓”；按成本暂估不代表取得当日市价。
- 费用补扣金额及日期，例如 `7388.HK买入费用；交易0.21＋补扣0.11 HKD（11-24）`；金额与交收处理遵守[完整费用规则](investment-valuation-and-fx-design.md#每笔买卖一笔完整金融费用)。
- 用户本人的简短备注、感想和个人称呼。

### 各处只写自己需要的信息

- 日期、账户、对方、分类、预算、本行金额已有字段时不重复，也不能用备注替代这些字段或冲销关联。关联记录可重复简短标的名以便识别。
- 投资记录写买卖和现金，费用流水写费用组成，转账写用途；不复述其他流水金额或可推导的价差、净收益、分步算式。自动估值流水金额是差额，备注仍需保留目标总资产。
- 操作规则放设计文档，整理批次及更正原因放审计，不写“已记某预算”“不重复支出”等系统说明。

## 历史整理与兼容性

逐项确认替换内容，保留无关及用户简短备注，不按关键词批量删除或在启动时自动清洗。先备份，在同一事务逐行校验旧值、只更新 `note` / `updated_at` 并保存前后审计；不调用估值重算，不改流水编号、金额、日期、账户、预算或关联。

先在隔离账本演练，再验证正式修改：逐表比较只允许指定文字、更新时间及新增审计变化，核对完整性、外键、财务统计和导出。交易事实及推算依据须可追溯，旧文字可由备份或审计找回。历史整理及验证结果见 Git 记录。
