# AI 代录与备注范式

## 目的与适用范围

2026-11-25：投资备注曾同时包含买卖明细、转账、费用、预算归属、计算过程和维护说明，多个页面重复显示。现在按记录职责保存事实，让日常查询简短可读；交易数量、报价、交易后现金仍没有独立字段，必须保留在投资备注中。

本规范适用于 AI 代录、新增系统自动备注和用户授权的历史备注整理，不强制改写用户手填文字，不限制手工备注长度。未来功能新增结构化字段后，再将对应事实移出备注，不能提前丢弃信息。

## 固定写法

采用“固定主体＋可选补充”：字段未知时省略，不补猜测值，不留空模板；普通记录默认一句、尽量 40 字内，投资记录通常 1—3 个短分句、尽量 120 字内。同日多笔买卖可以重复买卖分句。长度只是写作目标，信息完整优先，禁止机械截断。

| 记录 | 固定主体 | 示例 |
| --- | --- | --- |
| 普通支出 / 收入 | 具体用途或事项；没有额外信息可留空 | `洗衣`、`实习工资尾款` |
| 投资转账 | 标的或用途＋补款 / 入金 / 转出 | `中国财险买入补款` |
| 投资费用 | 标的＋买入 / 卖出费用；组成（有拆项时） | `中国财险买入费用；组成36.88＋1.43 HKD` |
| 投资买卖与估值 | 买入 / 卖出＋标的＋数量×单价；现金；必要的持仓及估值依据 | `买入中国财险2000股×17.00 HKD/股；现金0 HKD；持仓暂按成本估值` |
| 仅录账户估值 | 报价来源或特殊估值依据；没有额外信息可留空 | `券商App总资产` |
| 自动估值损益 | 估值至＋目标总资产＋币种 | `估值至 34000.00 HKD` |
| 账户备注 | 一句用途或余额口径；仅重复名称则留空 | `基金定投`、`总资产含现金与持仓` |

### 允许的一点扩展

只有主体不足以解释这笔记录时，才在末尾增加一句 `补充：……`，写事实或必要的不确定性，例如 `补充：均价由入金减费用反推`、`补充：未提供后续市价`。复杂交易可多写必要的买卖分句，不扩写为操作日志。

- 数量单位保持原始口径，不能把“手”改成“股”；报价没有提供时不假造单价。
- 无单价而只知道成交额时，用 `买入标的＋数量；成交额……` 替代乘式。反推数字必须标明依据。
- 有剩余旧持仓时，简要保留旧标的和估值基础，避免把交易后现金误当作账户总资产。
- `现金0`、`清仓`、`持仓暂按成本估值` 各有意义；无证据不能补成确定事实。按成本暂记不等于已取得当日市场报价。
- 用户本人的短备注、感想和个人称呼保留；本规范主要约束 AI 添加的说明。

### 各处只写自己需要的信息

- 日期、账户、对方、分类、预算、本行金额已有字段时不重复；为识别同一交易，可以在买卖、费用、补款中重复简短标的名。
- 投资备注保留买卖和现金事实，不复述已经单独记账的费用、补款及预算。费用组成仅放费用流水，补款金额由转账金额表达。
- 港股同一笔买卖的交易费和补扣费合并为一笔真实金融费用，组成及不同于成交日的补扣日期写备注，例如 `7388.HK买入费用；交易0.21＋补扣0.11 HKD（11-24）`。不拆两笔费用再建立冲销事项；账单金额与交收净额按[投资规则](investment-valuation-and-fx-design.md#每笔买卖一笔完整金融费用)核对。
- 自动估值流水金额是差额，备注中的目标总资产是另一项信息，因此保留目标值；账户、日期和“投资估值损益”标记已有专门显示，不再重复。
- 可由数量、单价、费用计算出的价差、净收益和分步算式，不再层层写入备注。未知单价时的成交额、旧持仓成本等仍需保留。
- “已记金融预算”“不重复支出”“由投资账户承担”“详见某页面”等常规操作说明放设计文档；“整理日期 / 批次”和更正原因放审计，不进入业务备注。
- 备注格式只影响展示和查询文本，不能用备注代替分类、预算或冲销关联等结构化数据。

## 历史整理与兼容性

本轮整理已核对的投资买卖、对应费用和补款、投资账户备注，以及现有自动估值流水。保留用户简短备注与无关流水。逐项选择替换内容，不按关键词批量删除，不在每次启动时自动清洗旧文字。

实际写入前创建完整 SQLite 备份；在一个事务中逐行校验旧值、仅更新 `note` / `updated_at`，保存完整前后审计及备份路径。直接更新备注，不调用估值重算、不重建自动损益流水，也不更改原流水编号、金额、日期、账户、预算、估值金额或任何关联。

验证：先在隔离账本演练，对所有表做前后比较，只允许指定备注、更新时间和新增审计变化；检查完整性与外键、账户余额、收支、预算和投资统计及 Excel 兼容。正式执行同样校验，确认持仓数量、报价、费用组成、现金及推算依据可追溯；原文字可从备份或审计找回。
