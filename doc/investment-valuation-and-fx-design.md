# 投资估值、本币总统计与汇率设计

## 目标

第四页“投资与汇率”维护账户总资产估值、区间损益、月统计和每日汇率；概况页据此显示 CNY / HKD 计价的总资产、总负债及净资产。投资价格损益按账户原币计算，与资产的汇率换算分开。

不建立单只股票、基金代码、份额、成本价或实时行情的结构化持仓系统；已知买卖事实仍可按[备注范式](recording-notes.md)保存在估值备注中。这里的“终点价格”统一定义为**投资账户期末估值**，即该账户在某日的总资产金额，而不是单个标的的单位价格。

## 已确认的账本边界

### 定投、入金和出金

实际资金在支付账户与投资账户间移动时记转账，例如“支付宝余额 → 支付宝基金账户”“银行卡 ↔ 券商账户”。本金移动不计入生活收入、支出或预算；投资账户内买卖也不把成交额另记为普通收支。

### 汇丰投资内的买卖、合并费用与现金补足

沿用“汇丰银行（港币）”与“汇丰投资（港币）”两个账户，不另拆现金、持仓账户。投资余额包括现金与持仓；卖出款默认留在投资账户，后续买入先用可用现金，活期仅补 `max(0, 买入成交额 + 完整费用 - 投资可用现金)`。账户总资产、待收款都不能当成可用现金；跨日交收按下文单独处理。

当日投资记录保存交易后总资产及必要的买卖事实。无后续市价时，持仓暂按成交成本估值；清仓后仍有现金或待收款，总资产不能填零。费用及补扣见[完整金融费用](#每笔买卖一笔完整金融费用)，各处备注使用[固定范式](recording-notes.md)。

账户明细的“投资买卖与估值”显示日期、总资产、损益及备注，零损益记录也显示；只受账户和日期筛选影响，独立于普通流水的类型、分类及分页。费用组成查看对应费用流水，普通账户不展示投资记录区。

### 同账户换仓与已知手续费

卖出旧持仓再买入新持仓属于账户内部变化，只为真实补款记转账，买卖各记一笔完整费用。先录入补款和费用，再保存交易后的账户估值，自动差额只反映价格损益，不重复扣费。备注保留两侧标的、数量、报价及交易后现金。部分卖出保留余仓；没有新市价时按原成本暂估，不能直接套用卖出价或清零。

### 卖出待结算与转回活期

在途卖出款仍属于投资总资产，不能提前计入活期或可提现现金；清仓且无其他资产时，总资产为扣费后的待结算净款。当前不另建在途账户或字段，在投资备注中写明待收金额。

交收后仍留在同一投资账户，只更新资金状态；总资产不变就不新增流水。实际转回活期时，按真实到账日期及金额记“投资账户 → 活期账户”转账。

### 跨日交收与活期另扣费用

买卖事实与完整费用按成交日记录，活期转账和换汇按银行真实记账日记录，不能提前扣活期。投资备注标明待收 / 待付，此阶段的估值为：

```text
投资净资产 = 持仓估值 + 已结算现金 + 待收交收款 - 待付交收款
```

待付是交收义务，不另记本金支出或价格损失；后续资金转入 / 转出改变账户余额，交收本身不再次确认投资损益。银行额外补扣按下节合并费用及交收净额处理。

### 每笔买卖一笔完整金融费用

按用户确认的代录规则，同一笔港股买卖的交易费与活期补扣合为投资账户的一笔“金融费用 / 金融预算”，在成交日确认，备注保留组成和补扣日期；不建立费用冲销事项，也不包含股票本金或换汇金额。原始查询、预算和 Excel 直接读取完整费用；零费用不创建零金额流水。

交收转账同步采用含全部费用的净额：买入为原交收扣款加补扣，卖出为原交收入账减补扣，两端一致，日期为实际交收日。对应待收 / 待付及净资产也按完整费用核算；中间日期提前体现补扣成本，但费用整理不产生额外价格盈亏。银行原分录通过费用组成及备份审计追溯。

整理旧账时，保留原费用编号与成交日，撤销对应的费用归并事项及独立补扣行，同步交收和估值；验证每日活期余额、交收后投资余额及同月费用总额保持一致。仅处理已确认的同笔费用，不更改其他事项，不把这一例外扩大为一般统计口径调整。

### 成交核算与实际余额存在未解释差额

1. 按已确认的成交序列核算价格收益、费用及期末持仓 / 现金。仍与银行余额不符时，用非估值的手工对账调整和“信息缺失”标记单列差额，备注保留核算余额、银行余额及差额，不混入收益、收入或费用。
2. 同日估值与调整在同一事务保存：估值取实际总资产，自动损益只反映已知价格收益，预算只增加已知费用。余额对齐不代表来源查清；差额未解释前保留标记，标准估值重算也须保持这一区分。
3. 查清后按[数据纠错规则](data-correction-design.md)更正原记录，采用最新确认的成交总额和费用，不沿用失效推算。若已完全解释差额，移除相应手工调整及标记，同步费用、估值和对账说明；定向更正保留原费用、估值、自动损益编号及实际余额，避免重复确认收益。预算只反映查实的费用差额。

### 代录与更正验证

- 写入前核对重复记录、原持仓、费用和实际资金路径；币种精度之外的输入先核实，用户暂不处理的成交不推测补录。
- 批量代录或已授权的更正先备份，在同一事务内保存并审计；无关流水、账户、预算计划、资金来源及关联保持不变。
- 在隔离账本核对成交日净资产、交收日活期余额、可用现金、余仓和换汇两端金额；费用只计一次，估值差额与系统标准重算一致，查询、预算和导出兼容。
- 仅整理文字时按[备注维护规则](recording-notes.md#历史整理与兼容性)处理，不重算金额或重建流水。

### 估值自动生成投资损益流水

保存估值会按下文公式生成单边 `adjustment`，由 `investment_valuations.generated_transaction_id` 关联，并显示为“投资估值损益”。它影响账户余额、净资产及导出，不计生活收支、预算或可用现金；手工调整没有此关联，须与投资损益区分。

金额、日期或账户应通过对应估值修改，通用流水编辑器禁止直接修改自动流水。保存或删除估值时，当前实现按日期重建该账户全部自动估值流水，后续余额随之重算；因此普通估值编辑不保证自动流水编号不变。自动备注采用[固定范式](recording-notes.md)。

## 数据对象

### investment_valuations

每个投资账户每天最多一条期末估值。

| 字段 | 说明 |
| --- | --- |
| `id` | 主键 |
| `account_id` | 关联 `accounts.id`，仅允许 `investment_asset` 或 `broker_cash` 类型的资产账户 |
| `valuation_date` | 估值日期 |
| `total_value_minor` | 当日账户总资产，按该账户本币最小单位保存 |
| `generated_transaction_id` | 系统自动生成的单边 `adjustment` 流水，唯一关联 |
| `note` | 可选备注，例如“招商证券 App 总资产” |
| `created_at`、`updated_at` | 创建和最后修改时间 |

约束：

- `(account_id, valuation_date)` 唯一；同日重复提交视为修改该日估值。
- 金额必须大于等于零。
- 前端新增、修改或删除估值前创建 SQLite 备份，并写入 `change_audit_logs`。

现有 `investment_snapshots` 保留为旧版通用快照和 Excel 兼容数据，不作为新投资页面的主数据源。

### daily_cny_exchange_rates

保存美元、港币兑人民币的每日自动汇率快照。汇率是报价，不是换汇流水。

| 字段 | 说明 |
| --- | --- |
| `id` | 主键 |
| `rate_date` | 该快照服务的本地日期，使用中国时区 |
| `usd_cny_rate` | `1 USD = X CNY` |
| `hkd_cny_rate` | `1 HKD = X CNY` |
| `source` | 公开汇率 API 名称，或 `manual` |
| `quoted_at` | 数据源返回的报价时间；无精确时间时为空 |
| `market_date` | 数据源实际适用日期；周末或假期时可早于 `rate_date` |
| `note` | 可选备注，例如人工覆盖原因 |
| `created_at`、`updated_at` | 创建和最后修改时间 |

约束：

- `rate_date` 唯一。
- 两个汇率均必须为正数。

保存 `USD/CNY`、`HKD/CNY` 后，可直接推导：

```text
1 CNY = 1 / usd_cny_rate USD
1 CNY = 1 / hkd_cny_rate HKD
1 USD = usd_cny_rate / hkd_cny_rate HKD
```

### 自动同步与人工兜底

启动后在后台补齐上海日期的当天快照，有记录即跳过；写入前复查，避免覆盖期间新增的手工记录。失败不阻止记账，服务关闭后不再落库；并发与取消规则见[启动性能设计](startup-performance.md)。只有显式 `force=true` 的同步允许覆盖。

投资页提供“同步今天汇率”和“手工覆盖”。同步 API 也支持指定历史日期；当前保存估值本身不会触发历史汇率补齐，缺失日期需另行同步或手工录入。快照保留来源、请求日期、报价时间及实际市场日期，周末报价可能早于快照日期。

历史报表只读已保存快照，缺失时按下文规则回退或提示，不因查看旧月份而联网改写结果。

## 估值与损益计算

### 自动流水生成与缺失估值

保存估值 `V(D)` 时，系统先计算该账户在 `D` 当天、排除本次估值流水后的账本余额 `B(D)`：

```text
投资估值损益流水金额 = V(D) - B(D)
```

- 结果大于零：生成流入投资账户的“投资估值损益”流水。
- 结果小于零：生成流出投资账户的“投资估值损益”流水。
- 结果为零：不生成金额为零的流水，但保留估值记录。

重算后每个估值日的余额须等于输入总资产。没有新估值的期间不生成损益，账面收益暂按零；真实资金流仍改变余额，补录估值后再更新损益及后续结果。

### 区间损益

对一个投资账户，查询区间 `(开始日, 结束日]`：

```text
区间损益 = 区间内“投资估值损益”特殊流水的净额
```

区间内定投、入金、出金只改变投资成本，不属于损益。两个投资账户之间的内部调拨也不构成损益。人工调整与自动估值损益通过是否关联 `investment_valuations` 分开显示，避免将数据纠错误认为投资收益。

当前只提供金额损益，不计算收益率；未来若支持收益率，应考虑逐日现金流而非简单相除。

### 月统计

月统计以上月末为开始日、所选月末为结束日，当前月截至当天，按账户显示投入、取出、期初 / 期末余额、损益及数据状态。

数据状态：

- `已估值`：本月存在实际估值，损益来自自动生成的估值损益流水。
- `按零收益`：本月没有新的估值，收益/亏损为零；定投和出金仍体现在账户余额。
- `无估值基础`：从未录入过估值，账户余额仅代表投入成本，收益/亏损为零。

## 第四页：投资与汇率

| 区域 | 当前操作 |
| --- | --- |
| 估值录入 | 选择启用的投资账户、日期（默认今天）、总资产及可选备注；同账户同日保存为更新 |
| 区间收益 | 选择单个或全部账户及日期范围，显示期初 / 期末余额、投入、取出、损益与状态 |
| 月度统计 | 选择月份范围及账户，逐月展示统计，无新估值也显示；展开时加载 |
| 每日汇率 | 查看 USD/CNY、HKD/CNY、来源及市场日期，支持同步今天和手工覆盖；展开时加载 |

## 概况页的人民币和港币总统计

按 CNY / HKD 分别换算所有可换算资产及负债，净资产为总资产减总负债。过去月份截至月末，当前月截至当天，前端禁止未来月份；各账户均取统计日账面余额，投资余额已含自动损益。

USD/HKD 汇率取统计日或之前最近快照并显示日期；无可用汇率的币种不计入合计，列为“待补汇率币种”，不能假设 1:1 或零。此规则不同于缺投资估值时暂按零收益。汇率历史和手工覆盖统一在第四页维护。

## API

### 投资估值

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/investments/accounts` | 获取可估值的投资账户 |
| `GET` | `/api/investments/valuations` | 查询估值记录 |
| `PUT` | `/api/investments/accounts/{account_id}/valuations/{valuation_date}` | 新增或更新某日估值 |
| `DELETE` | `/api/investments/valuations/{valuation_id}` | 删除估值 |
| `GET` | `/api/investments/performance` | 查询区间收益 |
| `GET` | `/api/investments/monthly` | 查询月统计 |

### 汇率

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/fx-rates` | 查询每日 CNY 汇率快照 |
| `POST` | `/api/fx-rates/sync` | 自动同步今天或指定历史日期的 USD/CNY、HKD/CNY |
| `PUT` | `/api/fx-rates/{rate_date}` | 手工覆盖某日 USD/CNY、HKD/CNY 汇率 |

### 概况

`GET /api/dashboard?month=YYYY-MM` 返回：

- `as_of_date`
- `base_currency_totals`：CNY 和 HKD 的换算总资产、总负债、净资产、待补汇率币种和汇率快照。

## Excel

当前导出包括“投资估值”“每日汇率”“本币总统计”，并保留兼容的“投资快照”；月度投资统计通过页面及 API 查询，没有独立的“投资月统计”工作表。费用和调拨见“交易流水”。Excel 只供查看，不回写估值或汇率。
