# 投资估值、本币总统计与汇率设计

## 目标

本阶段新增第四个页面“投资与汇率”，用于：

1. 记录基金和券商账户在某日的账户总资产估值。
2. 基于定投、入金、出金流水和估值，查询任意区间损益。
3. 按月查看投资账户的投入、取出、期末估值和区间损益。
4. 自动同步历史汇率，在“概况与查看”页显示人民币计价和港币计价的总资产、总负债和净资产。
5. 将投资本身的价格变动与汇率变动分开显示。

不建立单只股票、基金代码、份额、成本价或实时行情的结构化持仓系统；已知买卖事实仍可按[备注范式](recording-notes.md)保存在估值备注中。这里的“终点价格”统一定义为**投资账户期末估值**，即该账户在某日的总资产金额，而不是单个标的的单位价格。

## 已确认的账本边界

### 定投、入金和出金

资金真实移动仍由现有流水记录：

```text
支付宝余额 -> 支付宝基金账户
银行卡 -> 招商证券账户
招商证券账户 -> 银行卡
```

这些流水是投资账户的资金流，不计入生活收入、支出和预算。

### 汇丰投资内的买卖、合并费用与现金补足

2026-11-18 按用户确认更正：只使用“汇丰银行（港币）”与“汇丰投资（港币）”两个既有账户。投资账户表示现金与持仓的总资产，买卖是其内部资产形态变化；卖出款留在投资账户，下一次买入先使用已有现金。活期只在投资现金不足时转入差额，按 `max(0, 买入成交额 + 合并费用 - 投资可用现金)` 计算，保证本次代录每步现金不为负。不能用包含股票价值的账户总余额代替可用现金，也不因卖出而默认转回活期。

每次买卖的原手续费与补充费用合并为一笔投资账户的“金融费用 / 金融预算”支出，备注保留组成；合并后删除对应的独立附加费用行，备份和审计保留原记录。买卖数量、报价、交易后现金与必要的持仓估值依据写入当日投资记录（复用 `investment_valuations` 备注），缺报价时保留已知成交额及推算依据；费用组成只写在费用流水，补款流水只写用途，采用[固定备注范式](recording-notes.md)。总资产按实际可确认的现金加持仓估值填写，不在估值备注重复。账户清仓但仍持有卖出款时，总资产为留存现金，不能填零。价格损益由现有估值重算生成，不额外记普通收入。新买持仓在未提供后续市值前按成交成本暂记，按用户给出的成交日补录。

账户明细新增“投资买卖与估值”区，复用既有估值记录显示日期、总资产、投资损益与买卖 / 现金备注，费用组成见对应费用流水；按账户及日期范围查询，独立于原始流水分页和类型、分类等流水筛选，零损益记录也显示。普通账户不展示该区。原流水仍只记实际资金调拨、合并费用与自动估值损益，不把买卖成交额重复计为收支；Excel 沿用现有“投资估值”和“交易流水”导出。

修正前备份，在同一事务内更正原转账、移动并合并费用、更新投资记录与自动损益，逐项审计；保留无关流水、账户、预算计划和资金来源。隔离验证投资现金逐步非负、成交及费用明细可见、只转入不足额、费用不重计、总资产和价差收益一致，以及查询、预算和导出兼容。

### 同账户换仓与已知手续费

同一投资账户内卖出旧持仓、再用现金买入新持仓时，卖出本金和买入本金只是账户内部的资产形态变化，不另外生成收入、支出或账户间转账。实际从活期补入的资金记录为转账；买入和卖出手续费分别从投资账户记为“金融费用”，沿用该账户已有的金融预算归属。已单独记录的手续费不再次从估值中重复扣减。

已知成交价与原持仓账面成本时，价格增值通过交易日的账户总资产估值生成投资损益流水。先合并补款与两笔手续费，再保存交易后的完整账户估值，使自动生成的差额只反映价格损益；在估值备注保留旧标的卖出、新标的买入的数量、报价及现金余额，费用组成保存在对应费用流水，便于追溯。批量代录前核对重复记录、创建一次全库备份，业务记录与审计在一个事务中提交，并核对交易前后账户余额。

### 卖出待结算与转回活期

卖出款尚处于“在途资金”时，仍计入原投资账户总资产，不能提前计入活期余额或当作可提现现金。卖出手续费先从投资账户记“金融费用”，沿用已有金融预算；再记录交易后的账户总资产，使估值差额反映价格收益。清仓且没有其他现金、持仓时，账户总资产就是扣费后的待结算净款。成交额和卖出本金不新增普通收入。

当前不另建在途账户或字段，投资备注按固定范式记录“卖出标的＋数量×报价；在途资金……”，保留用户确认的“手 / 股”单位。结算后资金仍留在同一投资账户时，仅按实际情况更新备注；总资产没有变化就不新增收支或转账。实际转入活期时，再按真实到账日期和金额记录“投资账户 → 活期账户”转账。

代录前核对原持仓、手续费和重复记录，备份后将费用、估值及关联损益在同一事务中保存并审计。隔离验证投资账户余额等于交易后总资产、金融预算只增加手续费、活期及其他账户余额不变，原有流水与历史统计保持一致。

### 跨日交收与活期另扣费用

成交日与交收日不一致时，买卖事实与交易费按成交日记录，活期转账和换汇按银行真实记账日记录，不能为凑交易日现金而提前扣活期。尚未付款的买入与尚未到账的卖出在投资备注中分别标明待付 / 待收；该阶段投资账户记录净资产，即“持仓估值＋已结算现金＋待收交收款－待付交收款”。待付是交收义务，不是价格损失，不另建普通支出。后续转入补款或转出卖出款自动改变余额，交收本身不再确认一次投资损益。

交易内扣费与银行额外补扣按用户确认合并为同一笔投资账户的“金融费用 / 金融预算”，备注记录各组成及补扣日期。银行交收按含全部费用的净资金变动记录：买入转入额为原交收扣款加补扣，卖出转回额为原交收入账减补扣；日期仍为实际交收日。账本每笔交收表示银行相关分录的净额，不再保留另一笔补扣支出；银行原分录可由费用组成及备份审计追溯。

部分卖出后保留剩余数量；未提供新市场价时，明确按原成交成本暂估，不把余仓清零，也不自动用卖出单价充当期末市价。交易及交收备注按固定范式填写；必要的待收 / 待付信息允许保留。按用户要求暂不处理的后续成交，不推测价格、费用或交收金额。

隔离验证成交日净资产、交收日活期余额、费用只计一次、剩余持仓及换汇两端金额；新增估值的差额需与系统标准重算结果一致。代录使用一个备份与事务，审计全部新增记录，并保留所有旧流水、预算计划及关联。

### 每笔买卖一笔完整金融费用

2026-11-25 用户明确更正：交易内扣费与活期补扣直接合并为一笔真实费用账单，组成放备注，不使用冲销事项或其他统计归并。此规则替代先拆两笔、再组成费用事项的处理方式；同一笔买卖只有一条“金融费用 / 金融预算”支出，原始查询、账户明细、预算和 Excel 直接读取完整费用。

保留原投资账户费用流水编号与成交日期，金额改为全部费用之和，备注固定为“标的＋买入 / 卖出费用；交易组成，补扣金额（补扣日期）”。删除本轮用于归并这些费用的事项和单独补扣费用行，先备份并逐项留完整审计。费用账单只含费用，不包含股票本金或换汇金额；不影响其他冲销事项。

同步修正对应交收转账的两端净额，并把尚未交收阶段的待收 / 待付及净资产估值调整到含全部费用的口径。费用在成交日合并确认，中间日期的投资净资产会提前体现补扣成本；交收后的账户余额、活期每日余额、价格损益与同月预算总费用保持一致。投资损益流水金额不因费用整理产生额外盈亏；必要时只同步自动备注中的目标估值。

隔离验证原始流水查询无需切换口径即可见完整费用、三笔费用之和与整理前一致、相关费用事项及独立补扣行均已移除、其他真实流水及关联不变；核对每日活期余额、最终投资余额、预算、标准估值重算和 Excel。此为用户明确授权的费用账单合并，不将一般统计口径调整扩大为真实流水修改。

### 成交核算与实际余额存在未解释差额

已知买卖数量、成交价和费用时，先按完整序列核算价格收益、费用及期末持仓 / 现金。用户确认的银行实际余额若仍不一致，应将差额明确保留为待核实，不得把差额混入投资收益、普通收入或手续费。使用既有对账调整和“信息缺失”标记记录未解释差额，对账备注保留成交核算余额、银行余额及差额，方便之后核实。

同日投资估值与对账调整须在同一事务处理：投资估值取确认的实际总资产；未解释差额单独生成非估值的手工调整流水；与估值关联的自动损益仅包含已知成交价格收益。验证后续标准估值重算仍保持这一区分，预算只增加已知费用，其他账户与已有记录不变。银行余额已对齐不表示差额来源已查清，待核实标记必须保留。

查清来源后，按[数据纠错规则](data-correction-design.md)更正原调整流水或实际成交记录，并同步相关估值；不在保留调整的同时再补一笔相同收入。买入无费用不创建零金额费用流水；币种精度之外的输入先核实，不静默改成另一金额。

### 估值自动生成投资损益流水

每次保存账户期末估值，系统自动生成或更新一笔“投资估值损益”特殊流水。数据库中该流水复用已有的单边 `adjustment` 类型，并通过 `investment_valuations.generated_transaction_id` 关联：

- 估值上涨：流入投资账户。
- 估值下跌：流出投资账户。
- 不计入生活收入、支出、预算或可用现金。
- 计入账户余额、净资产、概况、账户明细和 Excel。

因此，用户只填写“某日账户总资产”，不需要手算损益或再额外记一笔调整；投资账户会由系统自动更新到该日真实估值。

该特殊流水在账户明细和流水查询中可见，并以“投资估值损益”明确标记。它不能使用通用流水编辑器直接改金额、日期或账户，因为这样会与对应估值脱节。修改方式是编辑该估值记录，系统在同一事务内重算该日及其后所有自动生成的估值损益流水；删除估值也会相应删除和重算关联流水。

自动备注固定为 `估值至 <目标总资产> <币种>`，不重复账户与日期。仅整理历史备注时直接更新备注并审计，不能为修改文字而触发上述重算；具体边界见[备注范式](recording-notes.md#历史整理与兼容性)。

人工发现账本错误时，仍使用既有“调整余额”功能。两者在数据库中都使用 `adjustment`，但投资估值损益有 `investment_valuations` 关联，前端、查询和 Excel 必须显示为不同状态。

## 新数据对象

### investment_valuations

每个投资账户每天最多一条期末估值。

| 字段 | 说明 |
| --- | --- |
| `id` | 主键 |
| `account_id` | 关联 `accounts.id`，仅允许 `investment_asset` 或 `broker_cash` 类型的资产账户 |
| `valuation_date` | 估值日期 |
| `total_value_minor` | 当日账户总资产，按该账户本币最小单位保存 |
| `generated_transaction_id` | 系统自动生成的单边 `adjustment` 流水，唯一关联 |
| `note` | 可选备注，例如“招商证券 App 总资产” |
| `created_at`、`updated_at` | 创建和最后修改时间 |

约束：

- `(account_id, valuation_date)` 唯一；同日重复提交视为修改该日估值。
- 金额必须大于等于零。
- 前端新增、修改或删除估值前创建 SQLite 备份，并写入 `change_audit_logs`。
- 保存、修改或删除任一估值时，系统按日期顺序重算该账户之后所有估值对应的自动流水。

现有 `investment_snapshots` 保留为旧版通用快照和 Excel 兼容数据，不作为新投资页面的主数据源。

### daily_cny_exchange_rates

保存美元、港币兑人民币的每日自动汇率快照。汇率是报价，不是换汇流水。

| 字段 | 说明 |
| --- | --- |
| `id` | 主键 |
| `rate_date` | 该快照服务的本地日期，使用中国时区 |
| `usd_cny_rate` | `1 USD = X CNY` |
| `hkd_cny_rate` | `1 HKD = X CNY` |
| `source` | 公开汇率 API 名称，或 `manual` |
| `quoted_at` | 数据源返回的报价时间；无精确时间时为空 |
| `market_date` | 数据源实际适用日期；周末或假期时可早于 `rate_date` |
| `note` | 可选备注，例如人工覆盖原因 |
| `created_at`、`updated_at` | 创建和最后修改时间 |

约束：

- `rate_date` 唯一。
- 两个汇率均必须为正数。

保存 `USD/CNY`、`HKD/CNY` 后，可直接推导：

```text
1 CNY = 1 / usd_cny_rate USD
1 CNY = 1 / hkd_cny_rate HKD
1 USD = usd_cny_rate / hkd_cny_rate HKD
```

### 自动同步与人工兜底

汇率默认不要求手工录入。后端完成本地初始化后，在生命周期管理的后台任务中执行以下流程，服务就绪不等待联网（见 [启动性能设计](startup-performance.md)）：

1. 用中国时区取得今天日期。
2. 查询 `daily_cny_exchange_rates` 是否已有今天记录。
3. 已有记录则不联网，不重复请求。
4. 没有记录则请求固定的公开汇率 API，获取 `USD/CNY` 和 `HKD/CNY`，并写入今天快照。
5. 写入前再次检查今天的快照，自动同步不覆盖请求期间保存的手工记录；显式强制同步仍可覆盖。
6. 请求失败记录错误日志，概况页继续使用最近可用快照，并明确显示汇率日期。关闭服务取消后台等待，不再保存该任务结果。

月末录入投资估值时，前端也调用“补齐该估值日期汇率”：

- 若该日期已有快照，直接使用。
- 若没有，则优先请求数据源的历史汇率接口并写入该日期。
- 如果数据源不支持该历史日期或请求失败，使用该日期之前最近一条快照，并标记“非当日汇率”。

这样即使没有在月末当天启动服务，后补月末投资估值时也会尽量补齐当月汇率。

投资页保留“同步今天汇率”和“手工覆盖”入口，但它们不是日常必填操作。手工覆盖仅用于网络不可用、公开数据源缺少数据，或用户希望按银行/券商实际换汇价统计的情形。

自动汇率来自一个固定的公开汇率数据源；实现时记录来源、请求日期、报价时间和实际市场日期。历史报表只使用已保存快照，不在查看旧月份时重新联网改写历史结果。

## 估值与损益计算

### 自动流水生成与缺失估值

保存估值 `V(D)` 时，系统先计算该账户在 `D` 当天、排除本次估值流水后的账本余额 `B(D)`：

```text
投资估值损益流水金额 = V(D) - B(D)
```

- 结果大于零：生成流入投资账户的“投资估值损益”流水。
- 结果小于零：生成流出投资账户的“投资估值损益”流水。
- 结果为零：不生成金额为零的流水，但保留估值记录。

若修改历史估值，系统必须依日期顺序重新计算其后的所有自动流水，使每个估值日的账户余额都精确等于用户输入的总资产。

没有新估值的期间，不生成新的估值损益流水；真实定投、入金和出金流水仍继续改变账户余额，未录入的投资收益或亏损按 `0` 处理。之后补录估值，系统自动补出该日应有的投资估值损益流水，并重算后续结果。

### 区间损益

对一个投资账户，查询区间 `(开始日, 结束日]`：

```text
区间损益 = 区间内“投资估值损益”特殊流水的净额
```

区间内定投、入金、出金只改变投资成本，不属于损益。两个投资账户之间的内部调拨也不构成损益。人工调整与自动估值损益通过是否关联 `investment_valuations` 分开显示，避免将数据纠错误认为投资收益。

第一版只提供金额损益，不计算收益率。定投发生在不同日期时，简单收益率会产生误导；以后若需要收益率，应基于每天现金流计算 XIRR。

### 月统计

月统计以每月最后一天为结束日、上月最后一天为开始日，显示：

- 当月投入。
- 当月取出。
- 月初和月末账户估值。
- 当月损益。
- 数据状态。

数据状态：

- `已估值`：本月存在实际估值，损益来自自动生成的估值损益流水。
- `按零收益`：本月没有新的估值，收益/亏损为零；定投和出金仍体现在账户余额。
- `无估值基础`：从未录入过估值，账户余额仅代表投入成本，收益/亏损为零。

## 第四页：投资与汇率

顶部导航新增第四页“投资与汇率”。页面包含以下不互相嵌套的区域。

### 估值录入

- 投资账户选择：仅显示启用的 `investment_asset`、`broker_cash` 资产账户。
- 估值日期：默认今天。
- 账户总资产：必填。
- 备注：可选。
- 同日已有数据时，显示为更新而非重复新增。

### 区间收益查询

- 账户：单个投资账户或全部投资账户。
- 开始日期、结束日期。
- 结果：期初余额、投入、取出、期末余额、区间损益、估值损益流水和数据状态。

### 月度投资统计

- 年月范围或年份选择。
- 按账户展示每月统计，可查看全部账户的合计。
- 没有新估值的月份仍显示，并明确标记“按零收益推算”。

### 汇率同步与查看

- 保存估值时默认自动同步该日汇率。
- 单独“同步今天汇率”操作，用于没有估值的启动日。
- 显示来源、快照日期、报价时间和实际生效日期。
- 手工覆盖入口默认收起，仅在自动同步失败或需要使用实际换汇价时使用。
- 可查看 USD/CNY、HKD/CNY，以及由两者推导出的 USD/HKD 历史汇率及变化。

## 概况页的人民币和港币总统计

“概况与查看”页新增两个汇总结果：

- 人民币计价总资产、总负债和净资产。
- 港币计价总资产、总负债和净资产。

每一种本币口径都会将所有可换算的资产账户和负债账户纳入统计；净资产等于总资产减总负债。学生贷款、花呗等负债也会按同一套汇率换算。

### 统计日期

概况页继续使用已有月份选择器：

- 选择过去月份时，统计截至该月最后一天。
- 选择当前月份时，统计截至当天。当前日期为 `2026-09-04` 时，选择 `2026-09` 即统计截至 `2026-09-04`。
- 前端禁止选择未来月份，避免产生没有账本和汇率数据的伪历史结果。

### 各账户的取值

截至统计日：

- 普通资产账户：使用该日的账本余额。
- 投资账户：使用账本余额；该余额已包含系统自动生成的投资估值损益流水。
- 负债账户：使用该日账本余额，换算后计入本币总负债。

### 汇率缺失处理

汇率与投资估值缺失的规则不同：

- 投资估值缺失：不生成新的估值损益流水，当期收益暂按零。
- USD/HKD 汇率缺失：优先使用统计日之前最近一条快照，并显示该快照日期。
- 从未有过可用快照：不能假设 `1:1` 或零；该币种的资产和负债都不计入对应本币合计，并在页面明确列出“待补汇率币种”。

这能避免把美元、日元等资产错误计入人民币或港币总额。

第二页不展示汇率变化；需要查看每日 USD/CNY、HKD/CNY 历史汇率或手工覆盖时，统一在第四页“投资与汇率”处理。

## API 草案

### 投资估值

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/investments/accounts` | 获取可估值的投资账户 |
| `GET` | `/api/investments/valuations` | 查询估值记录 |
| `PUT` | `/api/investments/accounts/{account_id}/valuations/{valuation_date}` | 新增或更新某日估值 |
| `DELETE` | `/api/investments/valuations/{valuation_id}` | 删除估值 |
| `GET` | `/api/investments/performance` | 查询区间收益 |
| `GET` | `/api/investments/monthly` | 查询月统计 |

### 汇率

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/fx-rates` | 查询每日 CNY 汇率快照 |
| `POST` | `/api/fx-rates/sync` | 自动同步今天或指定历史日期的 USD/CNY、HKD/CNY |
| `PUT` | `/api/fx-rates/{rate_date}` | 手工覆盖某日 USD/CNY、HKD/CNY 汇率 |
| `DELETE` | `/api/fx-rates/{rate_id}` | 删除汇率快照 |

### 概况

`GET /api/dashboard?month=YYYY-MM` 增加：

- `as_of_date`
- `base_currency_totals`：CNY 和 HKD 的换算总资产、总负债、净资产、待补汇率币种和汇率快照。
