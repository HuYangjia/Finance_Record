# 本地使用说明

## 第一次启动

项目已使用 SQLite 初始化空数据库：

```bash
.venv/bin/python -m scripts.init_db
.venv/bin/python -m uvicorn app.main:app --reload
```

启动后在浏览器打开 `http://127.0.0.1:8000`。

数据库文件位于 `data/finance.db`。应用每次通过前端写入数据前，都会在 `backups/` 创建一个 SQLite 备份。

## Windows 一键启动

在 Windows 文件资源管理器中双击 `scripts/start-wsl.cmd`。该脚本会通过默认 WSL 发行版启动服务，并自动将项目所在的 Windows 路径转换为 WSL 路径。

浏览器打开 `http://127.0.0.1:8000`。服务运行期间请保持脚本窗口打开；要结束服务，在该窗口按 `Ctrl+C`，或直接关闭窗口。

## 开始记账前

当前数据库已初始化人民币/港币现金、支付宝、微信、人民币/港币银行卡、券商账户和八达通账户，期初余额均为 0。可按 [database-manual.md](database-manual.md) 修改账户名称、机构和期初余额，或新增其他账户。

支付宝基金账户与花呗的记账规则见 [account-model.md](account-model.md)。

默认已创建 CNY、HKD、USD、EUR、JPY 五种币种，以及常用收入、支出分类。后续可直接在 `currencies` 与 `categories` 表扩展。

支出分类中，“食品杂货”用于早餐食材、生鲜、零食和其他自己购买回家食用的食品；“日常购物”用于纸品、清洁用品及其他非食品生活用品。外食、外卖等即时餐食归入“餐饮”。

给他人发工资、支付劳务费或兼职报酬时，使用支出分类“工资/劳务支出”；本人收到工资或劳务收入时，使用收入分类“工资/劳务”。

## 当前前端能力

- 首页只提供记账：新增一笔支出、入账、同币种转账或跨币种换汇。
- 首页左侧“常用操作”可预填八达通餐饮、微信转八达通，以及支付宝余额到支付宝基金的 35 CNY 每日定投；点击后仍需确认并保存才会创建流水。
- 通过顶部“概况与查看”进入独立页面，按月份查看收入、支出、结余、资产、负债和净资产。
- 概况与查看页面包含按 CNY、HKD 换算的总资产、总负债和净资产，账户内资金流动、最近 20 笔流水和当前月份的 Excel 导出。
- 通过顶部“账户与流水”查看单个账户的期初余额、累计流入/流出、当前余额和流水；账户明细、流水查询默认当前自然月，各自保留筛选范围。可点“本月、上月、本季度、本年、全部、自定义”，按月/季度/年用前后期按钮翻看。快捷日期保留账户、预算、类型等其他条件；“重置筛选”恢复本月并重置其他筛选。日期只限制查询，账户当前余额始终按完整流水计算。
- 同页“流水查询”支持跨账户查询，并可同时勾选多个流水类型、多个收入/支出分类；筛选区下方显示全部命中流水的原币种流入/流出/净流动，以及按已保存系统汇率折算的 CNY、HKD 合计和各流水类型小计，分页不影响总额。“全部”或手动清空两端日期查询全历史，只填一端则按单边界筛选，均有金额汇总。分类项直接读取数据库，也包含已停用的历史分类。
- 当流水查询选择完整日期范围（不超过 12 个月）和唯一一种流水类型时，结果下方的“流水详情”会按 HKD 展示日历、每日金额直方图、每日均值/中位数/方差等统计，以及星期、分类和账户分布；缺少当天汇率时使用日期最接近的已保存快照。
- 每笔流水可在“账户与流水”页修改、删除或标记待核实；删除、修改、标记、对账、余额调整和期初余额修正都会先在 `backups/` 创建备份，并在数据库中留下审计快照。
- 账户摘要显示最近对账状态。账实差异无法拆回具体流水时，使用“对账 / 调整余额”；建账日初始金额录错时，使用“修正期初”。
- 通过“投资与汇率”录入基金或券商账户总资产。系统会自动生成可查询的投资估值损益流水；修改历史估值会重算后续自动损益。
- 后端启动时会在当天缺少记录的情况下自动同步 USD/CNY、HKD/CNY 汇率。投资页也可手动同步或在必要时覆盖汇率；网络失败不会阻止本地服务启动。
- 支出模式默认选中八达通账户；八达通被停用或不存在时，自动改为第一个启用账户。

多预算计划和栏目现在通过“预算计划 / 设置”维护；对账与投资估值使用已有页面。旧版 `monthly_budgets` 和兼容投资快照仍保留原维护方式。相关字段和约束见 [architecture.md](architecture.md) 与 [transaction-entry.md](transaction-entry.md)。

## 冲销与代收代付

1. 照常在首页录入每一笔真实收入和支出。
2. 打开第五页“冲销与代收代付”，点击“新建事项”，选择“支出后收回”或“收入后分出”。
3. 在上方选择多笔主流水，在下方选择多笔冲抵流水。选择器支持日期、账户、分类、对象 / 备注筛选和跨页多选。
4. 日期自动取全部成员最早日期；分类继承最早一笔主流水，同日按流水编号排序。不需要填写统计时期、分类或起点。新增、移除和修改原流水后自动更新归属。
5. 点击“预览净额”查看原币分项和 CNY / HKD 结果，保存后生效。以后可以继续加入新记录，或移除已有关联。

概况页和账户与流水页的“流水查询”提供“原始收付 / 冲销后收支”切换，各页面分别记住自己的选择，初次默认原始口径。第三页还可选择“仅冲销事项（页面5）”，查询第五页组织的事项，也可直接打开第五页。冲销模式按自动归属的日期和分类统计；“涉及账户”命中后返回整个事项，不代表该账户实际流入 / 流出。展开事项可查看全部原始成员，包括其他日期、月份或账户的收付款。

支出冲销金额为支出减收回；收入冲销金额为收入减分出。允许零值、负支出和负收入，不要求两边相等，不设结清状态。跨币种按每笔原始日期的已保存汇率换算，缺当天快照时使用邻近快照；缺少任一成员的换算条件时，整个事项在该计价币种下显示“无法完整换算”，合计明确显示覆盖缺失。

“移除关联”或“解散事项”只改变统计关系，不删除原始流水。仍有关联的流水不能直接删除；先移除关联或解散事项，再从流水页删除。编辑原始金额后事项立即重算，编辑日期或分类也会更新事项归属。

Excel 跟随概况页所选口径，新增“个人收支”“冲销事项”“冲销关联明细”；关联明细包含完整成员。冲销模式另保留“原始月度总览”“原始月度预算”，账户余额、交易流水和内部资金流动始终保留原始记录。冲销模式预算按预算币种折算命中类别的完整记录，原始模式预算仍按原币种统计。

第一次启动新版本时，会先为已有账本创建 `finance-pre-offset-*.db` 备份，再添加事项表和审计约束。现有流水不会自动分组，需要自行选择。

## 第六页预算计划与设置

1. 在设置右侧建立自己的日常、专项等预算；左侧“未单独指定的支出计入”选择日常预算，历史消费也会自动归入。下方分别选择新支出和入账的预填预算。首次预置日常预算，入账默认未归属。
2. **预算系统就是用途**。例如已建“日常、慈善、留存”三个系统，新增预算的用途直接从这三个中选。设置中的“历史用途标签”仅用于维护旧记录，新预算不需要创建它。**存储方式由所有预算共用**：在设置中新增一次活期、定期、ETF 或子栏目，各预算即可选择。改名全局生效，分配金额各自独立；停用保留已有金额和历史。旧版栏目升级前备份为 `finance-pre-shared-storage-*.db`，相同路径及说明的重复项合并，有差异的项目保留预算名后缀。
3. **一个预算系统只有一种币种**。在设置中新建预算时可指定，也可留到首次编制时选择。打开“预算计划”，点击“新增预案”，在弹窗中选择用途、月份，填写一个总额，再分配到 ETF、定期等。以后月份和全部存储分配自动沿用这个币种；可先保存总额，以后补分配，不重复增加预算。已有计划点“编辑整份预案”也使用同一弹窗；“保存并关闭”成功后返回概览，失败保留草稿。取消、右上角关闭或 Esc 遇到未保存修改会先确认，点击背景不会关闭。
4. 九月等历史月份可以补录、修改，也可点击“上个月 / 下个月 / 回到本月”。保存只修订该月并更新后续累计。若之前币种选错，在计划金额旁改选币种，或点“修改预算币种”；设置的预算列表也有“修改币种”。预览列出该系统所有月份，确认后统一更正币种，**总额及每笔分配的数字不变**，金额由你再逐月修改。旧版本保留原币种。若有未保存草稿，请先保存或取消；目标币种不支持原金额精度时，先调整对应月份的金额。已有来源绑定时会重新核验占用额度，超限则整次更正不保存。
5. “预算用途 × 存储方式”总表按币种分别展示本月或累计安排，行是预算系统，列是存储方式，另列待分配及总额。相同存储路径合并成列，点击金额查看各份计划来源；支持一级存储汇总和交换行列。总额按每月最新计划累计，历史版本不重复计入。**累计安排未扣消费**；预算整体剩余看上方“预算执行与连续结转”的结转余额。当前消费尚未指定存储扣减，因此各存储格子还不是消费后的余额，不应通过减少历史计划来表示消费。
6. 若金额错误或其他窗口已更新计划，保存失败并保留草稿；取消切换、加载失败也保留草稿。版本冲突后可收起并重新打开获取最新数据，再核对修改。更正币种还会检查该系统所有月计划的版本，避免覆盖其他窗口的修改。
7. 复制其他月份先产生总额和分配草稿，保存后生效；不复制来源月份的收入绑定，目标已有绑定会保留并按新总额重新核验。“历史版本”保留每次保存时的金额、币种和来源信息。Excel 导出包含预算总额及来源状态、二级存储分配和分币种汇总，跟随当前已加载的筛选与累计区间。不同预算系统可以选不同币种，所以总表仍分币种展示。旧计划未填总额时暂按原明细合计展示，编辑确认后保存；旧金额与标签不会自动改写。

预案弹窗中的“收入来源”是可选项：可搜索一笔未加入冲销事项的普通收入，或一个收入冲销事项。事项使用扣除分出后的净收入；AA 等支出事项中的回款和事项内单笔收入不会重复成为来源。选中后可查看净额、其他预案占用、本预案可用、保存后的剩余及已绑定清单，也能打开原流水或事项。

同一来源可支持多个预算、多个不同月份，但这些预案当前总额合计不能超过来源净收入。例：净工资 10,000，日常计划绑定 4,000，专项计划最多再绑定 6,000；金额只填在预案总额中，不另填分配金额。修改同一预案不重复占用，存储分配也不再占一次。超额保存被拒绝并保留输入，可以调小总额、更换来源或主动解绑；未绑定计划仍可保存。

**绑定不会再增加一笔预算收入**，消费和自动结转也不会释放来源额度。下月只录新增预算，不把已结转的余额再绑定一遍。来源净额后续减少时，已有计划不自动缩小，概览和执行表会提示来源不足；可以逐步调小计划、换来源或解绑。普通收入要加入事项或删除、收入事项要解散或改方向时，先按提示解除相关预案的绑定。跨币种使用账本已保存的当天或最近汇率核验；来源币种、换算参考日及邻近日期提示在弹窗展示，缺少必要汇率时不能增加占用。首次升级绑定功能前备份为 `finance-pre-budget-funding-*.db`，旧预案全部保持未绑定。

第六页的计划金额仍由你填写，不自动使用收入或投资收益。新增的“预算执行与连续结转”单独计算实际消费后的剩余：上月结余＋本月新增－冲销后净支出。所有预算的正负结余都传到下月；没有计划的月份显示“未编制”，新增暂按零，但消费照常纳入。每月只填新增金额，不手动复制结余。存储分配不算消费，普通收入不再重复增加预算。修改历史计划、流水、冲销或汇率后，执行结果重新计算，原计划不会被扣小。

消费按原币记账并选择预算归属。执行比较沿用已保存的当天或最近日期汇率，将完整冲销事项折成预算币种；缺汇率或主流水跨预算时显示“未完整”，后续结余也不会伪装成准确金额。不同预算之间不混加币种。单币种升级前备份为 `finance-pre-budget-currency-*.db`，历史只有一个币种的预算自动继承。旧版若确有多币种，保留原记录和统计并提示待整理。

执行起点默认取该预算最早计划或支出月，期初为零。在“设置 → 预算系统 → 编辑”可指定起算月份及正负期初结余；这不影响账户期初。执行表“结转历史”可查看最近 12 个月，切换编制月份可查看更早历史；累计起始月只筛选计划总表，不清空执行结余。Excel 新增“预算执行”表，包含所选月的各项金额和不完整说明。升级前备份为 `finance-pre-budget-execution-*.db`。

## 给记账选择预算归属

首页支出、入账、转账有各自独立草稿，切换不会清空其他模式；刷新页面仍会丢弃未保存草稿。支出与入账可选“预算归属”，转账和换汇不计为预算消费。

自动预填顺序为：**本笔手选 → 命名预设 → 分类映射 → 模式默认**。支出不单独指定时计入日常预算，收入可保持未归属。手选结果不会被后续分类切换覆盖；点击“恢复自动预算”可重新套用规则。保存专项消费后，下一笔重新应用默认或分类规则。

两份工资可在“设置 → 收入 / 支出预设”建立“工资 A / 工资 B”，分别指定预算，按需预填分类和到账账户。学费、劳务支出等可在“分类映射”指定预算，不需要改账户或把真实分类复制多份。新设置只影响后续预填，不会重写历史记录。

查看日常消费：进入第三页“账户与流水 → 流水查询”，选择“预算归属：日常预算”“类型：支出”和完整日期范围后查询。明细、分页总数、汇总及图表均应用这个筛选。**以前及今后未单独标注的支出都自动计入日常，只需将少量非日常消费改为专项预算。**明细显示“日常预算 · 自动”，编辑时选择“日常预算（自动）”可清除单独标记并恢复日常归属。

更改新增记账的预填项，不改变旧流水的有效归属。日常预算即使改名，关联也保持。只有明确更改设置中的“未单独指定的支出计入”时，所有未标注支出才会一起改按另一预算统计。收入、转账、换汇和调整不因这条规则变成日常消费。

冲销口径下，一个事项的全部主方向流水属于同一预算时，整个净额归该预算，冲抵方即使在其他月份或标了其他预算也会完整参与计算。主方向跨预算时，单预算统计显示未纳入事项的提示及入口；查询全部预算仍只计一次。此时需要检查主流水归属或重新组织确实可分开的事项，不自动分摊金额。

第一次安装预算功能会在添加字段前备份为 `finance-pre-budget-*.db`；已有预算功能升级到日常自动归属规则时，备份为 `finance-pre-daily-budget-*.db`。原流水金额和单独标记不变，日常归属在查询时计算。开发测试未改动正式账本；若服务仍运行旧进程，请关闭后按原启动方式重新启动，再刷新浏览器。

## 验证

运行以下命令执行隔离冒烟测试；测试使用临时数据库，不会修改 `data/finance.db`：

测试依赖见 `requirements-dev.txt`（包含 HTTP 接口测试所需的 `httpx`）；未安装时先运行 `.venv/bin/python -m pip install -r requirements-dev.txt`。

```bash
.venv/bin/python -m unittest discover -s tests -v
```
