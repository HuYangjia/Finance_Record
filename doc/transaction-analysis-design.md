# 流水详情统计设计

## 目标

第三页“账户与流水”的“流水查询”继续承担逐笔明细、修改、删除和筛选功能。在查询结果之后新增“流水详情”区域，用同一组筛选条件提供按日期的日历、金额分布和行为统计。

该功能不是“消费日历”。它可用于查看任意一种流水类型，例如支出、入账、转账、换汇或调整。

## 启用条件

流水详情只在以下条件全部满足时查询和展示：

1. 已选择完整的开始日期和结束日期。
2. 开始日期不晚于结束日期。
3. 日期范围覆盖不超过 12 个自然月。
4. 流水类型只勾选一种。

未满足条件时，原有逐笔流水查询照常执行；流水详情区域只显示缺少的条件，不发起统计请求。

日期范围跨月时，日历按月连续展示。超过 12 个自然月时必须拆分查询，避免日历和图表过长、失去可读性。

## 与流水查询的关系

流水详情复用当前“流水查询”的筛选口径：

- 账户范围。
- 开始日期、结束日期。
- 唯一选中的流水类型。
- 已选分类。
- 已选的多个预算归属（并集口径）。
- 对象、分类或备注关键词。
- 仅手工调整、仅待核实状态。

统计使用独立接口读取所有符合条件的记录，不受逐笔列表每页 50 条的限制。

点击日历中有统计金额的日期后，系统将顶部日期范围改为该日，并刷新逐笔流水列表，方便继续编辑或核对当天明细。

## 主金额口径

不同流水类型的金额字段不同。流水详情统一使用以下“主金额”：

| 流水类型 | 主金额 | 统计含义 |
| --- | --- | --- |
| 支出 | 流出金额 | 支出金额 |
| 入账 | 流入金额 | 入账金额 |
| 转账、换汇、券商入金、券商出金 | 流出金额 | 转出金额 |
| 调整 | 调减使用流出金额，调增使用流入金额 | 调整绝对金额，并保留调增/调减方向 |

流水详情不会将多个流水类型混在同一个分布或均值中，因此前端要求只选择一种类型。

## HKD 统一换算

所有图表、日历、统计数据和排序统一以 HKD 展示，避免把 CNY、HKD、USD 的金额直接相加。

换算只读取已经保存于 `daily_cny_exchange_rates` 的快照，不会在查询历史数据时联网或改写历史汇率。

| 原币 | HKD 换算 |
| --- | --- |
| HKD | 原金额 |
| CNY | `CNY / hkd_cny_rate` |
| USD | `USD * usd_cny_rate / hkd_cny_rate` |

汇率选择规则：

1. 优先使用流水日期当天的快照。
2. 当天没有快照时，使用数据库中与流水日期距离最近的可用快照；日期距离相同则优先较早日期。
3. 没有任何可用快照，或币种不属于 CNY、HKD、USD 时，该笔记录不纳入 HKD 金额统计。
4. 页面必须显示直接 HKD 笔数、当天汇率换算笔数、邻近日期汇率换算笔数、排除笔数和未支持币种，避免把不完整结果误认为完整统计。

## 展示内容

### 日历

- 每个自然月一个月历，周一为每周第一列。
- 日期单元显示当天 HKD 主金额合计和流水笔数。
- 日期不在筛选范围内时弱化显示。
- 没有符合条件流水的日期不显示金额。
- 有金额的日期可点击，进入该日逐笔流水查询。

### 核心统计

以换算成功的**每日主金额合计**为样本，展示：

- 总金额（HKD）。
- 纳入统计笔数（用于核对换算覆盖，不作为均值、方差等统计样本）。
- 有流水天数和查询范围天数。
- 范围日均：总金额除以开始日至结束日的全部自然日，包含没有流水的日期。
- 有流水日均、中位数、最小值、最大值。
- 每日总额的总体方差和总体标准差。
- 最高金额日及该日总额。

中位数、极值、方差和标准差仅使用有换算成功流水的日期；没有流水的日期不作为金额为零的样本加入这些统计。方差使用总体方差，即除以有流水天数，不是抽样方差。

### 金额直方图

直方图展示每日 HKD 主金额合计落入各金额区间的天数：

- 分箱数量依据有流水天数自动确定，最多 8 个。
- 区间宽度使用 `1 / 2 / 5 × 10^n` 的整数 HKD 阶梯，避免出现两位小数边界。
- 每个柱显示整数金额区间、天数和相对高度。

### 补充视图

在不制造无法解释的自动结论前提下，页面还展示：

- 星期分布：周一至周日的 HKD 每日总额之和和有流水天数。
- 分类分布：适用于有分类的流水；未分类流水显示“未分类”。
- 主金额账户分布：支出显示支付账户，入账显示到账账户，转账类显示转出账户，调整显示发生调整的一侧账户。

当某个分布只有一个项目时可以不展示该分布，避免重复信息。

## API

新增只读接口：

```text
GET /api/transactions/analysis
```

参数与“流水查询”一致，但要求：

- `start_date`、`end_date` 必填。
- `transaction_type` 必填且只能是一种。
- `category_ids` 可重复。
- `budget_system_ids` 可重复，`0` 表示未归属；不传表示全部。旧 `budget_system_id` 保留为单选兼容参数。
- `account_id`、`keyword`、`manual_adjustments_only`、`flagged_only` 可选。

返回数据包含：

- 当前筛选条件与主金额标签。
- HKD 换算覆盖情况。
- 每日合计，供日历渲染。
- 核心统计。
- 直方图分箱。
- 星期、分类和账户分布。

该接口不创建流水、不修改汇率、不创建备份。

## 不在本次范围

- 不对汇率缺失的币种估算或假设 `1:1` 汇率。
- 不将多个流水类型或多种原币直接混合统计。
- 不生成“节省建议”、预算建议或行为评价。
- 不替代第三页原有逐笔流水表、编辑、删除和标记能力。
